Template:Start infobox page/doc

This is a documentation subpage for Template:Start infobox page.
It contains usage information, categories and other content that is not part of the original template page.

This template and its sister

are intended to facilitate the presentation of an infobox template and its documentation on the infobox template's own page. The documentation should be prepared as a
page. This template then assigns it the lefthand side of the infobox template's page, while the infobox template itself appears on the righthand side of the page, using this code: 
{| style="width:100%; background:transparent;"
|- style="vertical-align:top;"
| <!-----Lefthand side: documentation----->
{{documentation}}
| <!-------Righthand side: template------->

This template should be placed between <noinclude> and </noinclude> tags at the very top of an infobox template page, immediately before the start of the infobox's code thus:

<noinclude>{{start infobox page}}</noinclude><!--
-->infobox code starts here

The start and end-comment markers ("<!--" and "-->") are important as they remove the possibility of a spurious space appearing. The
template should then be placed within <noinclude> and </noinclude> tags on the first line after the end of the template code. For an example, see Infobox Machinima.
