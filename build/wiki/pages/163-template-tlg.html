Parameters[]

Named

With the exception of alttext, {{tlg}}'s named parameters are toggles that are either omitted (default) or activated (by being assigned a value such as "on", "yes", "true", "include", etc). They may be included in any order (see Examples below):

Parameter Action As in
braceinside Include innermost braces as part of the template link
bold
boldlink
boldname		 Renders the template link/name in bold
etc.
code Display output using the (monospaced) HTML <code> formatting
etc.
italic
italics		 Display any parameters accompanying the template link/name in italic/s
nolink Don't render the template name as a link
nowrap Prevent the insertion of line breaks (word wrap) in the output
subst Include a subst: prefix before the template link/name
|alttext=[text] Use [text] as the label for the template link
Unnamed

{{tlg}} may take up to ten unnamed parameters as parameters accompanying the template link (or name); see Examples below.
