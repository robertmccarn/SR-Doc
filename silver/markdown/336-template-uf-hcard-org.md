## Preserved source

```wikitext
{{Microformat message
| format = hCard
| data = an organization's details

| subtemplates =
* Use {{tl|start date}} for the date on which an organisation was "established", "founded", "opened" or otherwise started, [unless that date is before 1583&nbsp;CE](https://second-renaissance.fandom.com/wiki/Wikipedia:WikiProject_Microformats/dates).
* Use {{tl|URL}} for an organisation's URL.
* Use {{tl|coord}} for [coordinates](971-geographic-coordinate-system.md) associated with the organisation (e.g. the location of its headquarters). A [Geo microformat](1006-geo-microformat.md) will then make these coordinates parsable, e.g. for use in online mapping, downloading to a [GPS](972-global-positioning-system.md) unit, etc.
```
