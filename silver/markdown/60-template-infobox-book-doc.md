# Description
To use this template, copy the following code and fill in the appropriate fields.

# Syntax
<pre>{{infobox book
 | title       = 
 | image       = [e.g. "Example.jpg"]
 | imagewidth  = [e.g. "150"] [default: 210 pixels]
 | author      = 
 | illustrator = 
 | date        = 
 | publisher   = 
 | previous    = 
 | next        = 
}}</pre>

# Sample output

 | image       = Example.jpg
 | author      = Alice
 | illustrator = Bob

}}</pre>
