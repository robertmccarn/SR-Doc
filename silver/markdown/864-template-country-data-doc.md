# Template:Country data/doc

## Preserved source

```wikitext
{{documentation subpage}}

This template is transcluded if a flag template is used without the first parameter, or with an empty first parameter. It can be used to place an "invisible" flag icon, as an alternative to using {{tl|noflag}} (which adds a {{tag|span|open}} tag with padding at the size of a flag icon), if one item in a list of items with flags shouldn't have a flag icon. For example:
* {{flagicon|}} [Western Sahara](https://second-renaissance.fandom.com/wiki/Western_Sahara) (<tt><nowiki>{{flagicon|}} [Western Sahara](https://second-renaissance.fandom.com/wiki/Western_Sahara)</nowiki></tt>)
which looks the same as
* {{noflag|[Western Sahara](https://second-renaissance.fandom.com/wiki/Western_Sahara)}} (<tt><nowiki>{{noflag|[Western Sahara](https://second-renaissance.fandom.com/wiki/Western_Sahara)}}</nowiki></tt>)

For further instructions, please see: [WikiProject Flag Template](https://second-renaissance.fandom.com/wiki/Wikipedia:WikiProject_Flag_Template).
```
