# Gold narrative workspace

Gold holds proposed or accepted extensions; it never overwrites the Bronze/Silver source record. Add one Markdown file per claim-bearing record under a type directory, for example `gold/events/a-new-crisis.md`.

Each file needs YAML front matter with `id`, `kind`, `status`, `title`, `claims`, and `sources`. Accepted extensions require at least one source locator or an explicit `rationale`.
